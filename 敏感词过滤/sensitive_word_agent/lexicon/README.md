# 词库来源说明

> 本文件不会被中间件加载（`lexicon_dir` 只读取 `*.txt`）。

| 文件 | 内容 | 来源 |
|---|---|---|
| `涉枪涉爆词库.txt` | **完整类别词库**（434 词，已去重、清洗不可见空白字符） | [konsheng/Sensitive-lexicon](https://github.com/konsheng/Sensitive-lexicon) `Vocabulary/涉枪涉爆.txt`（MIT 许可） |
| `民生词库.txt` | 演示词：打人 | 同上（仅取 1 词演示） |
| `贪腐词库.txt` | 演示词：腐败 | 同上（仅取 1 词演示） |
| `本单位自定义词库.txt` | 演示词：内部测试代号 | 本样例自拟，演示自定义类别 |

## 为什么只完整收录「涉枪涉爆」一类？

konsheng/Sensitive-lexicon 追求覆盖面，**部分类别（民生、贪腐等）混有大量涉政词条
和真实人名**，不适合直接提交到本仓库，也不适合不经审核就用于政务场景——直接全量
启用会把市民的正常咨询/举报一并拦下。

「涉枪涉爆」类内容相对中性（枪支弹药、爆炸物的售卖/制作关键词），拦截语义无争议，
因此作为「真实规模词库」的样例完整收录。

**生产环境接入其他类别时，请逐词人工审核后再放入本目录。** 详见仓库内教程
`敏感词过滤/tutorial-sensitive-word-guardrail.md` 设计要点 3（教程位于样例上层目录，不随 artifact 部署）。
