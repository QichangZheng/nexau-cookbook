# 通知 / 通报 / 意见 — 写作模板

docx-report type: `notice`

## 适用场景

| 文种 | 行文方向 | 场景 |
|------|---------|------|
| 通知 | 下行 | 传达要求、部署工作、转发文件、告知事项 |
| 通报 | 下行 | 表彰先进、批评错误、传达重要情况 |
| 意见 | 上行/下行/平行 | 对重要问题提出见解和处理办法 |

## 标题格式

- 通知：XX机关关于XXX的通知
- 通报：XX机关关于XXX的通报
- 意见：XX机关关于XXX的意见

## 正文结构

### 结构一：部署工作类通知（最常见）

```
发文缘由段（不编号，直接起始）
一、总体要求
    （一）指导思想
    （二）基本原则
    （三）工作目标
二、主要任务 / 重点工作
    （一）任务1
    （二）任务2
    （三）任务3
三、工作要求 / 保障措施
    （一）加强组织领导
    （二）强化督促检查
    （三）做好宣传引导
```

### 结构二：告知事项类通知（简短）

```
事由说明段
具体事项段
执行要求段
结语：特此通知。
```

## 写作要点

1. 发文缘由段放在第一个 section，heading 留空，说明发文的依据和目的
2. 结语"特此通知。"放在最后一个 section，heading 留空
3. 最后一部分通常是"工作要求"或"保障措施"，体现督促落实
4. 通知可以一事多项，内容较灵活
5. 通报类正文侧重事实陈述 + 评价 + 要求，结语用"特此通报。"
